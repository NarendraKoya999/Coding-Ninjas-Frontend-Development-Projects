## 🚀 How to Run the Projects

### 🔹 For HTML/CSS/JS Projects

1. Open the project folder
2. Open `index.html` in your browser
   OR
3. Use Live Server in VS Code

### 🔹 For React Projects

```bash
cd project-folder-name
npm install
npm start
```
